# 5. 图谱与统计

### 5.1 图谱节点

| 节点 | 来源                                                              | 显示颜色 |
| ---- | ----------------------------------------------------------------- | -------- |
| 人物 | 设定卡（节点 ID `s:<sheetId>`）                                   | 朱砂色   |
| 地名 | 被设定籍贯引用或被关系引用的地名候选（节点 ID `p:<candidateId>`） | 松绿色   |

图谱支持关系视图与全景视图，按人物/地名和族群筛选，支持拖拽节点、拖拽画布、滚轮缩放、重排布局与重置视图。节点半径人物 `22`、地名 `18`（`GraphTab.tsx` → `NODE_R`）；缩放范围 `0.4–3`，滚轮步进 `1.12 / 0.89`。图谱数据由设定卡、关系与地名候选在前端派生（`src/lib/graph.ts` → `buildGraphData`）。

### 5.2 布局持久化

节点坐标持久化到当前项目 `.workshop/graph.md`（`graph.getLayout` / `graph.saveLayout`），不写入候选或设定文件。

- 渲染层加载时读取 `graph.md`；读取失败或没有坐标时回退为自动布局，不阻塞图谱展示。
- 坐标以节点 ID 为键：设定卡节点 `s:<sheetId>`，地名节点 `p:<candidateId>`（`src/lib/graph.ts` → `sheetNodeId` / `placeNodeId`）。
- 数据或容器尺寸变化时重新计算布局，再用已保存坐标覆盖当前仍存在的节点；已删除节点的坐标保留在文件中但不再参与布局。
- 拖拽结束且位移超过 **3px**（`DRAG_SAVE_THRESHOLD_PX`）时，提交当前**全部**节点坐标快照；保存失败仅提示，不阻塞交互，下次打开沿用自动布局。仅点选节点不会触发保存。
- 保存接口按提交内容整体覆盖 `graph.md` 的「节点布局」表，不做服务端合并。
- 「重排布局」只刷新本次会话的坐标与内存缓存，不立即写盘；再次拖拽后才持久化。
- `graph.md` 同时包含节点/连线快照（人物、地名与关系列表），供直接阅读；解析时只读取布局表与更新时间，快照不参与数据恢复。

### 5.3 统计

统计页读取当前项目 `.workshop` 下的 `candidates.md`、`sheets.md`、`relations.md` 后计算：

- 候选总数、收藏数、设定卡数与关系数。
- 族群、类型、字符数与关系类型分布。
- 理论词库组合量。

统计数据不单独持久化，每次打开页面按当前项目文件实时计算（`data.stats`）。

### 5.4 布局算法

`src/lib/graph.ts` → `computeLayout` 使用圆形初始化（半径 `min(width, height) * 0.36`），再进行斥力（最小间距 `90`）、弹簧边（目标长度 `150`，系数 `0.02`）与中心引力迭代；迭代次数为 `min(220, 80 + n * 4)`。计算结果作为自动布局，可被 `graph.md` 中保存的坐标覆盖。
