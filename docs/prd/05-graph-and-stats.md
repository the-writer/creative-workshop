# 5. 图谱与统计

### 5.1 图谱节点

| 节点 | 来源                                 | 显示颜色 |
| ---- | ------------------------------------ | -------- |
| 人物 | 设定卡                               | 朱砂色   |
| 地名 | 被设定籍贯引用或被关系引用的地名候选 | 松绿色   |

图谱支持关系视图与全景视图，按人物/地名和族群筛选，支持拖拽节点、拖拽画布、滚轮缩放、重排布局与重置视图。

### 5.2 导出

图谱可导出 1080 × 720 PNG。文件通过系统保存对话框写入用户选择的位置。

### 5.3 统计

统计页读取 JSON 后计算：

- 候选总数、收藏数、设定卡数与关系数。
- 族群、类型、字符数与关系类型分布。
- 理论词库组合量。

统计数据不单独持久化，每次打开页面按当前 JSON 实时计算。

### 5.4 布局算法

`src/lib/graph.ts` 使用圆形初始化与斥力、弹簧边、中心引力迭代计算布局。布局位置仅存在页面状态中，不写入 JSON。
