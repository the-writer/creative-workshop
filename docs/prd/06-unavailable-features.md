# 6. 不可用功能

当前版本仅保留「AI 详细设定」一个不可用入口。分享功能已整体移除（渲染层入口、弹窗与文案均不存在），不再以任何形式出现。

### 6.1 AI 详细设定

| 入口                 | 当前行为                      |
| -------------------- | ----------------------------- |
| 候选库 → AI 详细设定 | 显示“AI 详细设定暂不可用”弹窗 |

当前版本不包含 AI 实现、AI SDK 或任何网络请求；点击入口只显示说明弹窗，不修改数据（弹窗由 `src/components/common.tsx` → `ConfirmDialog` 承载）。

### 6.2 已移除的能力

| 能力 | 状态                                                                  |
| ---- | --------------------------------------------------------------------- |
| 分享 | 已整体删除：设置页不再包含「更多 / 分享」卡片与按钮，也不存在分享弹窗 |

删除范围为渲染层 UI 与文案（`src/components/SettingsTab.tsx`）；主进程从未注册分享相关 IPC 通道，`electron/preload.cts` 的 `window.workshop` 白名单亦无分享接口，故无接口兼容性影响。导出功能（JSON / TXT / Markdown / PNG）同样不提供。
