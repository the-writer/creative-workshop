# 6. 导出与不可用功能

### 6.1 可用导出

| 格式     | 内容                                           | 保存方式       |
| -------- | ---------------------------------------------- | -------------- |
| JSON     | 候选、设定卡、关系与导出时间                   | 系统保存对话框 |
| TXT      | 当前候选名称清单                               | 系统保存对话框 |
| Markdown | 设定卡、候选表、图谱节点/连线与 Mermaid 流程图 | 系统保存对话框 |
| PNG      | 当前图谱视图                                   | 系统保存对话框 |

渲染层只提交文件建议名与 Base64 内容。主进程验证文件名和扩展名，只允许 `.json`、`.txt`、`.md`、`.png`，再由系统对话框选择目标路径。

### 6.2 保留但不可用的入口

| 入口                 | 当前行为                      |
| -------------------- | ----------------------------- |
| 候选库 → AI 详细设定 | 显示“AI 详细设定暂不可用”弹窗 |
| 设置 → 打包源代码    | 显示“源码打包暂不可用”弹窗    |
| 设置 → 分享          | 显示“分享暂不可用”弹窗        |

这些入口不包含远程请求、AI SDK、源码 ZIP 实现或系统分享调用。后续恢复功能时应先更新本章节、`07-persistence-and-ipc.md` 与本索引。
