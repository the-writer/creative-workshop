# 世界观命名工坊

为虚构世界观生成人名、地名、官职与绰号的命名创作工具，支持组合规则、候选收藏、设定卡、关系图谱与多维统计。

## 功能模块

- 生成：按族群、类型、字数等规则批量生成命名，支持职业/特殊能力多选组合与 AI 详细设定
- 候选库：命名列表、筛选、收藏、备注、详情与加入设定
- 设定：人物设定卡（职业、官职、籍贯、绰号、契约、备注）与人物关系
- 图谱：关系图谱 / 全景图谱，力导向布局、拖拽缩放、节点连线详情
- 统计：族群、类型、字数、关系类型分布
- 设置：
  - 导出全部已保存设定为 Markdown（含设定卡、名称候选与全局图谱流程图）
  - 打包当前项目源代码为 ZIP，可保存到本地或调起分享

## 数据

- 名称候选、设定卡、关系记录均通过数据库持久化
- 词库与设定集位于 `src/data/lexicon.ts`，生成逻辑位于 `src/lib/generator.ts`
